Amar Dokan POS API

RESTful API for Amar Dokan POS, inventory, restaurant management, and multi-store marketplace. Phase 6 adds server-side barcode lookup, bulk inventory actions, inventory movement logs and the owner profile endpoints documented here. Note: this spec documents the most-used routes; the full route list lives in server/routes.ts.

Generated from server/openapi.json — run npm run docs:api after editing the spec. Served live at /docs; raw spec at /api/openapi.json.

/products/bulk

MethodPathSummaryResponses
POST /products/bulk Bulk inventory actions: adjust stock, set price, delete
Phase 6. Body: { ids (1-500), action: adjust-stock|set-price|delete, delta (adjust-stock, integer), price (set-price, >= 0), confirmed: true (delete only) }. Stock can never go negative; per-product skips are reported as { id, reason } and never hidden.		 200 { updated, deleted, skipped: [{ id, reason }] }
400 Invalid bulk request (incl. DELETE_NOT_CONFIRMED)
